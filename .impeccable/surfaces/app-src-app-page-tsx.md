# Landing `/`

Mode: Persuade. Audience: neobank and fintech decision makers. Sells, never operates. Brief-pinned Stockwoven design system; code-led.

## Direction contract

THESIS: One stock. One token. The landing shows the mechanism (separate pools → one woven token) in the brand's ink/ivory print language, then hands off to the app and the docs. It refuses the crypto landing with live widgets and yield promises.

OWN-WORLD: Ink hero and closing band with the generated weave full-bleed on the right half (fade toward text), ivory sections between them, bento tiles radius-lg / space-3, one inverse tile (the sw token in the flow), purple only on primary CTAs, sw prefixes, the holders' share of the fee and "Learn more" links. No eyebrow labels above headings.

STORY: Hero (tagline + what it does) → How it works (issuer tokens → pool → sw token, then Deposit/Hold/Redeem) → Where the conversion fee goes (split bar with on-chain sources) → Supported stocks (table) → For neobanks and fintechs → Questions (FAQ from docs) → Try the vault on devnet → footer. Section headings are plain descriptive labels, not two-beat slogans; the hero keeps the brand line. Unset external links are left out, never shown as [TODO].
